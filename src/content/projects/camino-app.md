A progressive web app for the Camino Portugués Central route. It keeps working when the trail has no signal. Add it to your iPhone home screen and it works like a native app.

## Features

- **Six stages** from Tui to Santiago de Compostela, with published distances
- **Live map** with GPS position and progress along the actual trail
- **Points of interest** from OpenStreetMap, including albergues, cafés, churches, and fountains
- **Works fully offline** because the app, route, and POI data are cached on your phone
- **Advanced mode** where you can customize stages, edit distances, and add your own POIs
- **Recommendations** with curated restaurants and bars, plus photos

## How to use it

A hosted version is coming soon. For now you can run it yourself from the source code (you'll need a free MapTiler key). See the repo's README for details.
